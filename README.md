# ORDA Web — сайт ФК «Ордабасы»

Десктопный сайт клуба (Next.js 15 + TypeScript, статический экспорт). Мобильное приложение живёт отдельно — в репозитории `FC-ORDA2`.

Превью: https://theeviltea.github.io/ORDAweb/ (собирается GitHub Actions при каждом пуше в `main`).

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # статический сайт в ./out
npm run typecheck
```

## Страницы

| Маршрут | Экран |
| --- | --- |
| `/` | Главная |
| `/team` | Команды клуба (основной состав + места под молодёжную, женскую, академию) |
| `/matches` | Расписание, результаты, турнирная таблица |
| `/media` | Медиацентр: новости, видео, фото, интервью, пресс-конференции |
| `/shop` | Каталог магазина |
| `/shop/product` | Карточка товара |
| `/shop/orders` | Мои заказы |
| `/fans` | Фан-зона |
| `/profile` | Личный кабинет |

## Как устроен код

- `src/app/**/page.tsx` — маршруты и метаданные страниц.
- `src/views/<Экран>/` — разметка экрана (`*View.tsx`), его логика и данные (`*.vals.js`), стили для отдельных эффектов (`*.css`).
- `src/components/` — общие части: `Icon` (Hugeicons), `Star` (звезда из брендбука), `PlayerCard`, шапка.
- `src/lib/` — `asset()` для путей к картинкам с учётом basePath, `route()` для ссылок, `useDC()` — состояние экранов.
- `public/img`, `public/fonts` — изображения и фирменные шрифты (SO Sporty, Roboto Condensed).

Сейчас данные (матчи, состав, новости, товары) — демо-контент из дизайна. Следующий шаг — подключить API клуба вместо констант в `*.vals.js`.

## Дизайн → код

Экраны собраны из дизайн-макета (canvas, страница «Веб») скриптами в `tools/canvas-import`:
они переводят разметку макета в TSX 1:1. После правок дизайна можно пересобрать экраны:

```bash
python3 tools/canvas-import/build_site.py <папка project макета> .
python3 tools/canvas-import/icons.py <hugeicons.json> .
npx prettier --write "src/**/*.{tsx,ts,js,css}"
```

Если экран начали править руками — дальше правим его в коде, а не перегенерируем.
